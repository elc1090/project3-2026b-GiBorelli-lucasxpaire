Modificações:

Primeiramente, criaremos dois cadastros diferentes: Professor e Estudante. O Professor poderá criar questões novas para a aplicação. O Estudante somente terá acesso a responder questões pré-definidas. Depois, iremos alterar o comportamento e registro das questões da aplicação, buscando maior flexibilidade no conteúdo delas e na correção dos gabaritos. Uma funcionalidade extra (ainda em discussão de viabilidade) seria a criação de Turmas, em que o Professor terá acesso aos dados de registro dos Estudantes e poderia definir quais questões eles podem acessar. 

> O Blockly é uma biblioteca de desenvolvimento de código aberto da Raspberry Pi Foundation, originalmente desenvolvida no Google. Ele cria uma interface de programação visual que utiliza blocos de arrastar e soltar.
